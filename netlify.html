請開始執行第一個步驟

1. 登入專案
2. 新增專案
3. 上傳檔案
4. 自訂網址
步驟 1

登入 Netlify 並進入專案頁面

確保您已經登入 Netlify 帳號，並從主主控台進入專案管理分頁。

操作指引：

  • 前往 Netlify 主畫面，查看畫面左上角。
  • 點擊 Projects (專案) 選項以進入專案總覽。
步驟 2

建立新專案

在 Dashboard 或 Projects 頁面準備一個新的發佈空間。

提示： 初次使用 Netlify 的全新帳號可能會自動跳過此步驟。

操作指引：

  • 在 Dashboard 或 Projects 頁面右上角。
  • 點擊青綠色的 Add new project (新增項目) 按鈕。
步驟 3 (關鍵步驟)

拖曳資料夾上傳

將您在電腦上的網頁資料夾或 HTML 檔案直接上傳部署到伺服器。

  • 找到畫面中央第 3 個區塊 (Upload your project files)。
  • 看到大矩形虛線框，標示：
    "Drop a project folder, zip file, or HTML file to deploy instantly."
  • 可直接拖曳資料夾，或點選 browse files to upload / choose a folder。

重要提醒：

若系統詢問 「Rename to index.html?」，請務必點選 「Rename and deploy」，網站首頁才能被伺服器正確辨識！

將專案資料夾拖曳至此處

支援 Folder、ZIP 或 HTML 檔案

步驟 4

建立公開網址名稱與完成發布

部署完成後，Netlify 會生成隨機網址。您可以自訂為好記的專屬名稱。

  • A 點選 「Make public」 或點選 「編輯 (鉛筆圖示)」。
  • B 輸入自訂網址名稱。 規範：只能包含英文小寫數字與連字號 (-)
  • C 按下 ✅ (確認) 或點擊 Make public 保存變更。
